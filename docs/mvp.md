# Flow AI MVP

## First workflow

1. Enter a brief describing the topic, audience, and tone.
2. Choose a content format. Start with a social post or a short video script.
3. Generate a draft and copy it for further editing.

## Implementation sequence

1. Build the frontend workflow with sample drafts.
2. Add a backend generation endpoint and keep provider credentials on the server.
3. Connect the form to the endpoint and handle loading, success, and errors.

Authentication and draft history can be considered after the first workflow is working.
